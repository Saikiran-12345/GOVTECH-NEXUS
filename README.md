# GovTech Nexus — Intelligent Government Services & Public Administration Platform

GovTech Nexus is an enterprise-grade digital government services and public administration platform designed for high performance, transparency, citizen engagement, and operational efficiency.

## Architecture
- **Backend**: FastAPI, SQLAlchemy 2.0, PostgreSQL, Alembic, Pydantic v2
- **Frontend**: React 18, TypeScript, Vite, TanStack Query, Lucide Icons

## Quick Start
- **Backend Docs**: http://localhost:8000/docs
- **Frontend App**: http://localhost:5173
